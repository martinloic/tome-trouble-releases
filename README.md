# Tome Trouble

A cozy co-op game for 1 to 4 players: little librarians sort and shelve books in a magic library.
Un jeu coopératif et paisible de 1 à 4 joueurs : de petits bibliothécaires rangent les livres d'une bibliothèque magique.

## Download / Télécharger

**[Latest version / Dernière version](https://github.com/martinloic/tome-trouble-releases/releases/latest)**: take the zip for your system.

- **macOS** (Intel and Apple Silicon): unzip, then open `Tome Trouble.app`. The app is not notarized, so macOS blocks the first launch: *System Settings > Privacy & Security > Open Anyway* (older macOS: right click > Open).
  L'app n'est pas notarisée : au premier lancement, *Réglages Système > Confidentialité et sécurité > Ouvrir quand même*.
- **Windows** (64-bit): unzip the whole `Tome Trouble` folder and keep the `.dll` next to `Tome Trouble.exe`. SmartScreen may warn: *More info > Run anyway*.
  Dézippe tout le dossier et garde la `.dll` à côté de l'exe. Si SmartScreen prévient : *Informations complémentaires > Exécuter quand même*.

All players must run the same version to play together.
Tous les joueurs doivent avoir la même version pour jouer ensemble.

This repository only holds the builds; the game's source is private.
